Tus datos se guardan en la nube (Firebase). Las ventas se sincronizan entre todos los dispositivos donde entres con tu sesión: metas la venta en el móvil, la tablet o el ordenador y aparece en todos. Además, se guarda una copia en cada dispositivo por si te quedas sin internet. Aun así, es buena costumbre pulsar “Guardar copia” al final de cada día.

¿No sincroniza? Suele ser por dos motivos: (1) no has iniciado sesión en el sistema en ese navegador —abre el menú y entra— o (2) faltan permisos en Firebase. Si es lo segundo, en la consola de Firebase → Firestore → Reglas añade dentro de match /databases/{db}/documents: 
match /feria_ventas/{id} {
  allow read, write: if request.auth != null;
}
match /feria_meta/{id} {
  allow read, write: if request.auth != null;
}
